# Application Workflow

1. Start the application.
2. Register a new user or select Login.
3. After authentication, open the dashboard.
4. Add income and expense transactions.
5. Set the current monthly budget.
6. View individual transaction lists.
7. Generate the financial report.
8. Delete an unwanted expense if required.
9. Logout and return to the main menu.

## Report Calculation

`Balance = Total Income - Total Expenses`

`Remaining Budget = Monthly Budget - Total Expenses`
